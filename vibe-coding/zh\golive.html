第 5 步（共 5 步）

你的域名和 Google 登录

按需要连接自有域名或设置 Google 登录，并逐步验证结果。

选你需要的：A 是用你自己的网址，B 是 Google 登录。点一下打开，再一步一步点开来看。

AI 负责代码、主机设置、在 GoDaddy 里点击（用 Claude 桌面 app），还有检查一切都正常。
你负责GoDaddy 要你登录时自己登录（AI 绝不会帮你打密码），还有自己设置 Google 登录。
A · 连接你的域名你自己的网址，例如 www.yourshop.com›

例子：域名在 GoDaddy 买，网站放在 Railway。大约 10 分钟，之后可能要等几个小时。

  1. 0先把 Railway 连接到 Claude先做这个，每台电脑做一次就好。第 1 步需要它›

    Claude 需要权限，才能改你 Railway 账号里的东西（加域名、读取记录）。选一种方法：

    方法 1 · 通过 Railway 插件登录（最简单）

    1. 在 Claude Code 里输入 /plugin，安装 railway（一次就好）。
    2. 输入 /mcp → 选 railway → Authenticate。
    3. 浏览器会打开 Railway → 登录 → Allow。回到 Claude Code，它会显示已连接。

    方法 2 · 把 Railway token 放在私人文件里

    1. 建立 token。打开 railway.com/account/tokens（或点左下角你的名字 → Account Settings → Tokens）。输入一个名字，例如 claude-myproject，选你的 workspace，点 Create。
    1. 复制它。Railway 只会显示新 token 一次，就在 New Token 下面的框里。点复制图标。
    1. 把这个提示词贴进 Claude Code。Claude 会建立一个私人文件，在你的编辑器里开成一个分页（名叫 .env）。把 token 贴进那个文件，不要贴进聊天里，按 Ctrl+S 保存，然后在聊天里只打 pasted 这个词。

    贴进 Claude Code

    我想让你帮我管理这个项目的 Railway 账号。
建立一个私人设置文件来放 Railway token（不要上传到 GitHub），
帮我打开它，我会自己把 token 贴进去。然后检查你看不看得到我的 Railway 项目。

    完成的标志：Claude 列出你的 Railway 项目。然后去第 1 步。

    token 要保密。绝对不要把它贴进聊天或截图发出去：任何人看到它都能控制你的项目。万一发生了，或项目结束了，就在同一个 Railway 页面用垃圾桶图标删掉它。

  1. 1在 Claude 桌面 app 里用一个提示词搞定其余的它会加域名、打开 GoDaddy、做好修改，然后一直检查到成功为止›
    1. 在下面的框里输入你的域名，点 复制，然后贴进 Claude 桌面 app。
    2. Claude 会在它自己的浏览器里打开 GoDaddy。GoDaddy 要你登录时，由你自己输入密码和代码。之后 Claude 会继续做。
    3. 它会给你看改了什么，然后一直检查，直到你的网站能用新网址打开。这可能要几分钟到几个小时。

    贴进 Claude 桌面 app

    我在 GoDaddy 买了 yourdomain.com，想让它显示我放在 Railway 上的网站。

1. 在 Railway 上，把 www.yourdomain.com 加到我的网站（如果已经有了就直接用）
   并拿到它需要的 DNS 记录。
2. 在你的浏览器里打开 GoDaddy，去 yourdomain.com 的 DNS 页面。
   如果要我登录，就停下来让我自己登录。绝对不要帮我打密码或代码。
3. 只做这几个修改：
   - 把 www 的 CNAME 记录设成 Railway 给的值，
   - 加上 Railway 的 TXT 验证记录，一字不差地照抄，
   - 把 yourdomain.com 转址到 https://www.yourdomain.com（Permanent 301，只转址，不要 masking）。
   保存转址时，GoDaddy 可能会自己换掉 "Parked" 记录。这是正常的。
4. 别的什么都不要改，不要改 nameservers，什么都不要买，不要接受任何加购推销。
   如果画面跟预期不一样，停下来问我。
5. 准确告诉我你改了什么。
6. 从外部一直检查（用公共 DNS，不要只看这台电脑，因为它可能会记住旧的
   地址一个小时），直到 Railway 显示域名已验证，而且 https://www.yourdomain.com
   能打开我的网站。成功了就告诉我，也告诉我不加 www 的 yourdomain.com 转址了没有
   （这部分可能要几个小时）。
7. 然后列出我项目里还在用旧网址的地方（付款完成后的返回页面、
   电邮里的链接、登录设置），改任何上线中的设置之前先问我。

    在框里输入你的域名，然后点 复制。不是在 GoDaddy 买的，或网站不是放在 Railway？贴上后把那些字改掉就好。

    没有桌面 app？叫 Claude Code 把第 2–4 步写成给 Claude in Chrome 用的提示词，在 Chrome 登录 GoDaddy，再贴进 Claude 侧边栏。

    Google 账号：B 部分请自己动手做。让浏览器 AI 进你的 Google 账号，风险比进 DNS 页面大得多。

B · 用你自己名字的 Google 登录客人用他们的 Gmail 登录，不用新密码›

登录窗口会显示你 Google app 的名字，所以每个品牌都要有自己的 app。在 console.cloud.google.com 大约 10 分钟。

  1. 1建立项目项目选择器 → New project›
    1. 点顶部的项目选择器 → New project。
    2. 用你的品牌名字命名 → Create → 确定已经选中它。

  2. 2填写同意画面App 名字、电邮、External›
    1. APIs & Services → OAuth consent screen（可能写着 "Google Auth Platform"）→ Get started。
    2. App name = 你的品牌。支援和联络电邮 = 你的电邮。Audience = External。
    3. Branding → 在 Authorised domains 下加上你的域名 → Save。

  4. 4建立网页客户端把你网站用到的每个网址都加进去›
    1. Clients → Create client → 类型选 Web application。
    2. Authorised JavaScript origins → + Add URI，每个网址加一次。要用 https，结尾不要斜线。
    3. "Authorised redirect URIs" 留空 → Create。

  1. !“Error 400: origin_mismatch”Google 挡住了登录窗口›

    错误画面（示意图）

    accounts.google.com
    Access blocked: Authorization Error
    You can't sign in to this app because it doesn't comply with Google's OAuth 2.0 policy. Error 400: origin_mismatch

    贴给 AI

    Google 登录在 [页面网址] 显示 "Error 400: origin_mismatch"。
准确告诉我要在 Authorised JavaScript origins 下面加哪个网址。
  2. !除了你，其他人都显示 “Access blocked”app 还在 Testing 状态›

    做第 B3 步：发布 app，让状态显示 In production。

  3. !yourdomain.com 显示停放页面转址还没设好，或记录放错了名字›

    转址可能要几个小时才会生效。如果过后还是显示停放页面，就叫 Claude 检查转址，还有 CNAME 的 Name 是 www，不是 @。

  4. !过了几个小时还是 “not verified”通常是 TXT 记录打错字›

    通常是 TXT 记录打错字。叫 Claude 从外部检查（提示词在下面）。

    贴给 AI

    我的域名还是没有验证成功。从外部检查我的 DNS 记录，准确告诉我
哪一条记录错了，应该改成什么。
