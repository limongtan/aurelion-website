graphify: help Claude find things faster

It gives Claude a map of your project.

⚡Fasteranswers
🔋266xless of your Claude limit*
🎁Freeto use

*Per question, on our big project. On a small project, about 10x.

Set it up in 2 steps

1Open Claude Code in your project folder 2Paste this, press Enter

The prompt

Install graphify from https://github.com/Graphify-Labs/graphify (pip install graphifyy, then graphify install). Run /graphify . on this project, open graphify-out/graph.html, then run graphify claude install so you always check the graph first.

If Claude asks for permission, say yes.

Your map looks like this

Each dot is a part of your project. The lines show what connects to what. Then just ask Claude as normal.

Changed a lot? Refresh the map

/graphify . --update
