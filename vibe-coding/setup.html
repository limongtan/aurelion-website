Before you start

What to prepare, and what to allow

The AI can only use what you give it, and only do what you let it.

Prepare

  • Your content.Texts, prices, phone numbers, photos, logo. The AI should never invent these.
  • A design, if you have one.From an AI design tool, Canva, a screenshot of a site you like. If you don't have one, the AI can design it, but expect more rounds.
  • Every file the design uses.Download the whole folder (photos, fonts, styles), not just the pages.
  • VS Code with Claude Code.Claude Code needs a paid Claude plan. It installs other tools it needs and tells you.
  • A GitHub account.Free. Your project's online backup and history.
  • A hosting account.Railway, Cloudflare and others. Small websites cost little or nothing; systems with a database cost more.
  • For systems only:a payment account (e.g. Stripe), an AI account (e.g. Google Gemini, Anthropic), an email sender. Each one gives you a secret key.
  • A domain, later.Not needed to start. The host gives a free web address.

Three safety rules

  • Never paste passwords or keys into the chat.Save them in a private settings file or in the host's settings. The AI reads them from there.
  • Keep the GitHub repo private.Make it public only if you really mean to share the code.
  • Real customers, real money, real messages: ask first.Anything that charges, deletes or sends to customers waits for your yes.
