Real example

Life Garden: from a design file to a live business

A coaching business had a finished design on a laptop. These are the owner's real messages, typos included, and what the AI did after each one. Result: lifegarden-production.up.railway.app

  1. 01

    Say what you want

    now i want to do a new website but not related to aurelion. its an another new product. but use the aurelion insight exactly same.

    • "Exactly same" could mean the same look, the same whole system, or the same layout with new colours. Very different amounts of work, so the AI asked which.

    Lesson: say what to copy and what to change.

  2. 02

    Hand over the design

    i already design use this. C:\Users\you\Downloads\lifegarden-final.html

    • Opened it, listed every section, and found the button the designer had marked for a product to plug in later.

    Lesson: pasting a file path is how you show the AI something on your computer.

  3. 03

    Ask the beginner questions

    just modify abit front end … domain i havent create. i will buy a domain later. do i need to create a workspace or github first

    • No domain needed yet. Use a separate folder and a private GitHub repo. Sell on WhatsApp first.

    Lesson: "do I need X first?" lets the AI plan the order.

  4. 04

    Create the GitHub repo

    please help me create a repo in github

    • The installer needed Windows admin rights and the popup was cancelled, so the AI used a version that needs no admin.
  5. 05

    Sign in to GitHub

    ABCD-1234 cannot. what is code

    • "ABCD-1234" was only an example. The AI started the sign-in itself and gave the owner the real one-time code.

    Lesson: confused? Say so at once, with a screenshot.

  6. 06

    First save online

    ok done

    • Created the private repo and uploaded the design as version 1.
  7. 07

    Give the full site and the goal

    …\LifeGarden\Reference — Can you refer to this folder and build the website? and then push to railway

    • Found 6 pages, but the photo and style folders were missing. It listed exactly what was missing instead of publishing a broken site.

    Lesson: give it the whole folder.

  8. 08

    Build, test, publish

    please check again

    • Checked all 37 photos, fonts and scripts, and looked at every page in English and Chinese, on laptop and phone.
    • Fixed a bug: switching browser tabs stacked extra animations (6 running after 5 switches; now always 1).
    • Saved to GitHub and connected Railway. Live in about a minute.
  9. 09

    Look at it like a customer

    i tot is milky colour, lifegarden-final.html. why is green one?

    • Cause: the pages switched to a dark version on dark-mode phones. Made the milky look the default. Live again in about 40 seconds.

    Lesson: open the live site on your own phone. "It looks different from what I expected" is a perfect bug report.

  10. 10

    Add the product and payment

    now help me plugin the aurelion insight and payment to life garden

    • Asked a few questions first: whose bank account, where the report lives, which login. Then wrote a plan and had a second AI check it.
    • Built it in 11 small steps, each one reviewed. A final review caught a serious bug before launch: paid reports would not open.

    Lesson: for anything with money, let the AI ask questions and show a plan before it builds.

  11. 11

    Buy a domain

    i already bought life-gardens.com. please help me proceed to next step

    • Added www.life-gardens.com to the host and listed the 3 changes to make at GoDaddy: one CNAME, one TXT, one forwarding.
  12. 12

    Too hard? Hand the clicks to Claude in Chrome

    its too hard to me, can you copy a prompt, and i put it at claude chrome

    • Wrote one prompt with the exact values and safety rules (change nothing else, buy nothing, stop at any login code). The owner pastes it into Claude in Chrome, which does the clicking in GoDaddy.

    Lesson: the coding AI can't log into your accounts, but it can write the instructions for a browser AI that can. See Go live for the template.
