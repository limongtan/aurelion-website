第 3 步（共 5 步）

要准备什么，要允许什么

AI 只能用你给它的东西，也只能做你允许它做的事。

准备

  • 你的内容。文字、价格、电话号码、照片、标志。这些 AI 绝对不应该自己编。
  • 设计，如果你有的话。可以来自 AI 设计工具、Canva，或你喜欢的网站截图。如果没有，AI 也能帮你设计，不过要多来回几次。
  • 设计用到的每个文件。把整个文件夹下载下来（照片、字体、样式），不要只下载页面。
  • 装了 Claude Code 的 VS Code。Claude Code 需要付费的 Claude 配套。它需要的其他工具会自己安装，也会告诉你。
  • 一个 GitHub 账号。免费。是你项目的网上备份和修改记录。
  • 一个主机账号。Railway、Cloudflare 等等。小网站几乎不用钱，有数据库的系统会贵一些。
  • 只有系统才需要：付款账号（例如 Stripe）、AI 账号（例如 Google Gemini、Anthropic）、发电邮的服务。每一个都会给你一把密钥。
  • 域名，以后再说。一开始不需要。主机会给你一个免费网址。

允许

权限为什么需要怎样给注意安全
运行指令、修改文件用来做、测试和保存Claude Code 每个动作前都会问你；你也可以让它直接做，不用每次都问每个项目放在自己的文件夹。在你信任它之前，一个一个批准。
读取文件夹你的设计和照片放在那里把文件夹路径贴到聊天里指定那个文件夹就好，不要给它整个硬盘。
安装程序像 GitHub 工具这类Windows 可能会跳出“允许更改？”的窗口看清楚名字。只用官方来源。
GitHub 账号建立 repo、上传版本在 github.com/login/device 输入一次性的 8 个字母代码随时可以取消：GitHub → Settings → Applications。
主机账号建立项目、发布登录一次，或把访问密钥存在你电脑里的私人文件项目结束后删掉密钥。
让主机读取 GitHub这样每次保存都会自动上线在主机的网站上批准一次只允许它需要的 repo。
付款、AI、电邮的密钥只有系统才需要存在主机的设置里，绝对不放进代码先用测试模式。设好花费上限。
花钱主机、域名、AI 使用费每次都由你说可以在第一个提示词里定下规则：“任何要花钱的事，先问我”。

三条安全规则

  • 绝对不要把密码或密钥贴进聊天里。把它们存在私人的设置文件，或主机的设置里。AI 会从那里读取。
  • GitHub repo 要设成私人。除非你真的想公开代码，才设成公开。
  • 真的客人、真的钱、真的消息：先问。任何会收钱、删除或发给客人的事，都要等你说可以。
